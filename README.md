# CalFlow 🗓️

> A simple, intuitive, calendar-first task and schedule management web application.

---

## 🚀 Quick Start

### 1. Backend Setup
```bash
cd server
npm install
cp .env.example .env
# Fill in your MONGODB_URI and JWT_SECRET
npm run dev
```

### 2. Frontend Setup
```bash
cd client
npm install
cp .env.example .env
npm run dev
```

---

## 🛠️ Tech Stack
- **Frontend:** React 18, Vite, Tailwind CSS, React Router v6, date-fns, Lucide React, Axios
- **Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT, bcryptjs, Helmet, CORS
- **Database:** MongoDB Atlas
- **Deployment:** Vercel (Frontend), Render/Railway (Backend)
